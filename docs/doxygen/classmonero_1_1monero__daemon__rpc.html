Get block hashes as a binary request to the daemon.

Returns
) before start_height is ever consulted
Parameters

max_block_countcaps how many blocks the daemon returns in one call (0 leaves it to the daemon's own default limit); use this to chunk large ranges instead of taking whatever the daemon hands back
Returns
the retrieved blocks plus the daemon's current chain height; the blocks are not a lookup of block_hashes, so their heights won't line up with block_hashes 1:1; the range starts at and includes the resume point (the common block found, or start_height itself when non-zero), not the block after it; if block_hashes[0] already matches the daemon's tip, an empty block list comes back (this noop check runs before start_height is consulted)
